# Undangan Digital

Template undangan pernikahan mobile-first dengan nuansa elegan, animasi scroll, countdown, guest parameter, galeri, lokasi, amplop digital, dan RSVP demo.

## Demo guest name

Buka dengan query:

`/?to=Andi%20dan%20Siti`

## Database

Schema Supabase belum dibuat karena akun saat ini sudah mencapai batas project gratis. Jangan memakai project `Dasboard` untuk data undangan karena project itu berisi sistem rumah makan.

Saat project Supabase khusus undangan tersedia, sambungkan frontend ke project tersebut dan pindahkan RSVP dari `localStorage` ke tabel database.
